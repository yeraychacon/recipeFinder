# RECIPE FINDER MICROSERVICE
This microservice is developed in node.js and is used to obtain recipes by ingredients.

#### INSTALATION ⚙️
To run it, tou need to download or clone the repository and have Node.js installed.

You need to download the following dependencies:

**axios, config, dotenv, express, nodemon and spoonacular**

To do this, run the following command:

    npm install axios config dotenv express nodemon spoonacular
